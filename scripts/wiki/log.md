# Log

Change history for the Learn ASIC Flow wiki — newest first. Entries are grouped by ISO-8601 date, each line `**[Action]**: description`.

## 2026-08-07

- **[Update]**: Renumbered the step pages from `00` rather than `03` — they are step indices, not global course positions, so `steps/` now runs [00 Simulation](steps/00_sim.md) → [14 Post-P&R power](steps/14_post_pnr_dpa.md). 15 files renamed; every link target, and every link label carrying a number (`[04]`, `[04 Synthesis]`, `[04_syn.md]`), rewritten with it.
- **[Update]**: Dropped the `learn-asic-flow/` folder level — the bundle now lives directly at `scripts/wiki/`, alongside the flow scripts it documents. All 56 links that reached outside the bundle lost one `../` accordingly.
- **[Update]**: Restructured the course from a flat `NN_*.md` list into the wiki layout used by the design projects under `projects/` — `wiki/` with `concepts/`, `steps/`, `references/`, plus a catalog [index.md](index.md) and this log. The step pages keep numbers so the pipeline order stays visible in the filenames; the concept and reference pages drop theirs, since their position is what [index.md](index.md) records. Page content is unchanged apart from the split and the new footers below.
- **[Creation]**: Split the old `00_overview.md` in two, following the wiki's separation of catalog from content. Its narrative half — the pipeline diagram, the tool and PDK inventory, and the repository conventions (`SEL_*` parameters, run-directory layout, picoseconds, `clk_i`, in-repo flow code) — became [ASIC flow pipeline](concepts/pipeline.md). Its catalog half — the course table and "How to read" — became [index.md](index.md), rewritten into the wiki's `* [Title](path) — description` idiom and given an explicit **Reading order** section.
- **[Update]**: Added a `Source:` footer to every page, linking the flow scripts it documents. Previously those appeared only as inline code spans (`` `scripts/pnr/1_floorplan.tcl` ``) with **no** relative links out of the course at all — so the documentation could not be navigated into the code, and a moved script left no trace. Each footer also carries a `Reference:` link to [asic_flow.md](../asic_flow.md) and an `Index:` link back.
- **[Update]**: Rewrote 110 internal cross-links for the new folder layout. `19_knobs.md` alone carried 45 of them.
- **[Note]**: Categorization rule, for future pages. `steps/` is one page per pipeline stage — the walkthrough of the scripts that implement it — and [05 P&R overview](steps/05_pnr_overview.md) sits there rather than in `concepts/` because it introduces that stage group. `concepts/` holds what the steps assume but do not implement: the pipeline itself, the PDK, the constraint scheme and the hierarchical macro loop. `references/` holds lookup material rather than reading material.
